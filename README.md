# Определение года события по упоминанию сановников — ЛР2

`Услуги` — `dignitarie_lists`: сановники (визири, консулы, воеводы) с датами пребывания в должности.
Поля по теме: `start_date` — дата вступления в должность и `end_date` — дата оставления должности.

## База данных (PostgreSQL, GORM)

| Таблица                 | Поля                                                                                                                                                                                                  |
|-------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `users`                 | `id` PK, `login` varchar(50) unique                                                                                                                                                                   |
| `dignitarie_lists`      | `id` PK, `name` varchar(255), `description` text *(необязательное)*, `status` varchar(20) (черновик/опубликован/удален), `image_url` varchar(500), `video_url` varchar(500), `start_date` date *(необязательное)*, `end_date` date *(необязательное)*, `created_at` — дата создания, `published_at` — дата формирования *(необязательное)*, `creator_id` FK → users |
| `dignitarie_list_likes` | `id` PK, `user_id` FK → users, `dignitarie_list_id` FK → dignitarie_lists, unique(user_id, dignitarie_list_id)                                                                                          |

- Необязательных полей четыре: краткое описание, две даты по теме и дата формирования. Название, url фото и url видео заполняются по кнопке «Далее», остальное — по кнопке «Опубликовать».
- Каскадного удаления нет (`ON DELETE RESTRICT`). Один черновик на пользователя — частичный уникальный индекс `idx_one_draft_per_creator`.

## HTTP-методы (6)

| Метод | URL                                                                          | Что делает                                              | Как                                |
|-------|------------------------------------------------------------------------------|---------------------------------------------------------|------------------------------------|
| GET   | `/dignitarie_lists/catalog?date=1570-01-01`                                  | плитка, фильтр — календарь с кнопкой «Найти»            | ORM                                |
| GET   | `/dignitarie_lists/feed`, `/dignitarie_lists/feed?id=3`, `?id=3&next=true`   | лента, из БД возвращается одна строка                   | ORM                                |
| GET   | `/dignitarie_lists/draft`                                                    | черновик пользователя или форма создания                | ORM                                |
| POST  | `/dignitarie_lists/draft`                                                    | «Далее» — создание черновика                            | ORM                                |
| POST  | `/dignitarie_lists/draft/publish`                                            | «Опубликовать» — смена статуса                          | ORM                                |
| POST  | `/dignitarie_lists/delete` (поле `id`)                                       | логическое удаление                                     | SQL `UPDATE`, курсор `sql.Rows`    |

- Файлы при создании на сервер не передаются — форма отправляет только имена файлов, в БД записываются неверные url. Если url пустой или файл недоступен, показываются фото и видео по умолчанию из `static/img/`.
- Вместо ответа 404 выполняется перенаправление на плитку: для удалённой или несуществующей услуги и для любых неизвестных адресов.

## Запуск

1. `cp .env.example .env` (Postgres снаружи на порту 5433)
2. Поднять Postgres, Adminer и Minio:
   ```bash
   docker compose up -d
   ```
3. Создать таблицы:
   ```bash
   go run ./cmd/migrate
   ```
4. Заполнить данными: Adminer http://localhost:8081 (PostgreSQL, сервер `db`, пользователь/пароль/БД из `.env`) → «SQL-запрос» → содержимое `seed.sql`.
5. Запустить сервер:
   ```bash
   go run ./cmd/dignitarie_lists
   ```
   Открыть http://localhost:8080/dignitarie_lists/catalog
